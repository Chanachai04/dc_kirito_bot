# 🤖 Kirito Bot

บอท Discord สำหรับจัดการระบบมอบหมายงานและติดตามความคืบหน้าของงาน โดยมีการเชื่อมต่อฐานข้อมูลเข้ากับ **Google Sheets** แบบเรียลไทม์

---

## ⚠️ การแก้ไขบั๊กไลบรารี gaxios (สำคัญมากก่อนการ Build .exe)

หากคุณ `npm install` หรือมีการลบโฟลเดอร์ `node_modules` แล้ว `npm install` ใหม่ **มันจะทำการโหลดไลบรารี `gaxios` เข้ามาใหม่** ซึ่งไลบรารีตัวนี้มี **บั๊กที่ไม่รองรับการนำไปคอมไพล์เป็นไฟล์ .exe ด้วย `pkg`** (จะทำให้เกิด Error `Invalid host defined options`)

ก่อนที่คุณจะรันคำสั่ง `npm run build` ในครั้งถัดๆ ไป คุณจะต้องเข้าไปแก้โค้ดในไฟล์ของไลบรารีด้วยตัวเอง ดังนี้:

1. เปิดไฟล์ต่อไปนี้ขึ้นมาแก้ไข (ถ้าเจอทั้ง 2 ไฟล์ ให้แก้ทั้ง 2 ไฟล์):
   - `node_modules/gaxios/build/cjs/src/gaxios.js`
   - `node_modules/googleapis-common/node_modules/gaxios/build/cjs/src/gaxios.js`
2. ค้นหาคำว่า `await import('node-fetch')` (จะอยู่แถวๆ บรรทัดที่ 530)
   โค้ดเดิมจะหน้าตาประมาณนี้:

   ```javascript
   this.#fetch ||= hasWindow
     ? window.fetch
     : (await import("node-fetch")).default;
   ```

3. ให้แก้ไขเปลี่ยนโค้ดส่วนนั้นเป็นแบบนี้:

   ```javascript
   this.#fetch ||= hasWindow
     ? window.fetch
     : typeof global !== "undefined" && global.fetch
       ? global.fetch
       : require("node-fetch");
   ```

4. เซฟไฟล์ แล้วจึงค่อยรันคำสั่ง `npm run build` เพื่อแพ็กโปรแกรมเป็น `kirito.exe` ครับ

## 📂 ไฟล์ที่จำเป็นก่อนเปิดใช้งาน

เพื่อให้โปรแกรมทำงานได้ คุณต้องแน่ใจว่ามีไฟล์ 4 ไฟล์นี้อยู่ในโฟลเดอร์เดียวกัน:

1. `kirito.exe`- ไฟล์โปรแกรมหลัก (ได้จาก npm run build)
2. `.env` - ไฟล์เก็บตั้งค่าความลับ (Token ของ Discord, Access Key, และ Spreadsheet ID)
3. `credentials.json` - ไฟล์กุญแจสำหรับใช้ยืนยันตัวตนกับ Google API (Service Account)
4. `node_modules` - โหลดไลบรารีที่ใช้ (ได้จาก npm install)

---

## ⚙️ การตั้งค่าไฟล์ .env

คุณจำเป็นต้องสร้างไฟล์ `.env` ไว้ในโฟลเดอร์เดียวกับโปรเจกต์ (หรือโฟลเดอร์เดียวกับ `.exe`) โดยต้องมีตัวแปรดังต่อไปนี้:

```env
DISCORD_TOKEN=โทเคนของบอท_Discord
SPREADSHEET_ID=ไอดีของ_Google_Sheets
```

**คำอธิบายแต่ละตัวแปร:**

- `DISCORD_TOKEN`: โทเคนของบอท (หาได้จากหน้า Bot ใน Discord Developer Portal)
- `SPREADSHEET_ID`: ID ของ Google Sheets (ดูได้จาก URL ของไฟล์ Sheets เช่น `https://docs.google.com/spreadsheets/d/ที่นี่คือไอดี/edit`)

## 🔑 วิธีการขอไฟล์ credentials.json (Google Sheets API)

บอทตัวนี้จำเป็นต้องเชื่อมต่อกับ Google Sheets จึงต้องใช้ไฟล์ `credentials.json` จาก Google Cloud Platform เพื่อยืนยันตัวตน โดยมีขั้นตอนดังนี้:

1. ไปที่เว็บไซต์ **[Google Cloud Console](https://console.cloud.google.com/)**
2. สร้างโปรเจกต์ใหม่ (Create Project)
3. ไปที่เมนู **APIs & Services** > **Library** แล้วค้นหาคำว่า **Google Sheets API** จากนั้นกด **Enable**
4. ไปที่เมนู **APIs & Services** > **Credentials**
5. กดปุ่ม **+ CREATE CREDENTIALS** ด้านบน แล้วเลือก **Service account**
6. กรอกชื่อ Service account (เช่น `kirito-bot`) แล้วกด Create and Continue ไปจนเสร็จสิ้น
7. เมื่อได้ Service account มาแล้ว ให้คลิกเข้าไปที่อีเมลของ Service account นั้น (หน้าตาจะคล้ายๆ `ชื่อ@ชื่อโปรเจกต์.iam.gserviceaccount.com`)
8. ไปที่แท็บ **KEYS** > กด **ADD KEY** > **Create new key**
9. เลือกประเภทเป็น **JSON** แล้วกด Create ระบบจะทำการดาวน์โหลดไฟล์ลงเครื่องของคุณ
10. **เปลี่ยนชื่อไฟล์**ที่ดาวน์โหลดมาเป็น `credentials.json` แล้วนำไปวางไว้ในโฟลเดอร์เดียวกับบอท (`kirito.exe`)
11. **ข้อควรระวังสำคัญ:** อย่าลืมเข้าไปที่ Google Sheets ของคุณ กดปุ่ม "แชร์" และนำอีเมลของ Service account (จากข้อ 7) ไปเพิ่มสิทธิ์ให้เป็น **Editor (ผู้แก้ไข)** เพื่อให้บอทสามารถเขียนข้อมูลลงไปได้

## 📥 วิธีหาไฟล์ yt-dlp.exe และ ffmpeg.exe

ระบบฟังเพลงของบอทตัวนี้จำเป็นต้องใช้โปรแกรมเสริม 2 ตัวนี้วางอยู่โฟลเดอร์เดียวกับ `kirito.exe` เสมอ เพื่อช่วยทะลุบล็อค YouTube และแปลงสัญญาณเสียง:

1. **วิธีหาไฟล์ `yt-dlp.exe`**
   - ให้เข้าไปที่ลิงก์ดาวน์โหลดอย่างเป็นทางการ: [ดาวน์โหลด yt-dlp.exe](https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp.exe)
   - เมื่อโหลดเสร็จแล้ว ให้นำไฟล์มาวางไว้ในโฟลเดอร์เดียวกับบอท

2. **วิธีหาไฟล์ `ffmpeg.exe`** (ทำได้ 2 วิธี)
   - **วิธีที่ 1 (ง่ายที่สุด):** หากคุณเคยรันคำสั่ง `npm install` แล้ว ให้เข้าไปในโฟลเดอร์ `node_modules/ffmpeg-static/` ในโฟลเดอร์โปรเจกต์ของคุณ คุณจะเจอไฟล์ `ffmpeg.exe` ซ่อนอยู่ในนั้น ให้ Copy ออกมาวางคู่กับไฟล์บอทได้เลย
   - **วิธีที่ 2:** เข้าไปดาวน์โหลดด้วยตัวเองจาก [gyan.dev](https://www.gyan.dev/ffmpeg/builds/ffmpeg-git-essentials.7z) (แตกไฟล์ .7z แล้วเข้าไปในโฟลเดอร์ `bin` จะเจอไฟล์ `ffmpeg.exe` ให้นำออกมาวางคู่กับบอท)

## 🚀 วิธีการเปิดใช้งาน (รันบอท)

1. ต้องมีไฟล์ต่อไปนี้อยู่ในโฟลเดอร์เดียวกันเสมอ (ห้ามแยก):
   - `kirito.exe` (ตัวเปิดบอท)
   - `yt-dlp.exe` (ตัวช่วยดึงเพลง)
   - `ffmpeg.exe` (ตัวช่วยแปลงสัญญาณเสียง)
2. ดับเบิลคลิกที่ไฟล์ **`kirito.exe`**
3. จะมีหน้าต่างหน้าจอสีดำ (Terminal/Console) โผล่ขึ้นมา
4. โปรแกรมจะถามหา **Access Key** (รหัสผ่าน)
5. ให้พิมพ์รหัสผ่านลงไป
6. หากรหัสผ่านถูกต้อง หน้าจอจะขึ้นข้อความว่า:
   ```text
   ✅ ยืนยันรหัสผ่านสำเร็จ กำลังเชื่อมต่อเข้าสู่เซิร์ฟเวอร์...
   [READY] Connected as ...
   ```
7. เท่านี้บอทก็พร้อมใช้งานในเซิร์ฟเวอร์ Discord ของคุณแล้ว! ห้ามปิดหน้าต่างสีดำนี้เด็ดขาด (หากปิดบอทจะออฟไลน์ทันที)

## 💬 คำสั่งบอทที่รองรับ

### 🎵 ระบบฟังเพลง (พิมพ์ปกติ)

ระบบฟังเพลงนี้จะใช้งานโดยใช้ Prefix `!` นำหน้าคำสั่งในช่องแชทปกติ

- **`!play <ชื่อเพลง หรือ ลิงก์>`**: ค้นหาและเล่นเพลงจาก YouTube ถ้ามีเพลงเล่นอยู่แล้วจะทำการเพิ่มลงคิว (ต้องอยู่ใน Voice Channel ด้วยถึงจะเรียกได้)
- **`!list`**: เรียกดูรายชื่อเพลงทั้งหมดที่อยู่ในคิว
- **`!next`**: ข้ามเพลงที่กำลังเล่นอยู่ ไปเล่นเพลงถัดไปในคิว
- **`!stop`**: หยุดเล่นเพลง ล้างคิวทั้งหมด และเตะบอทออกจากห้องเสียง

### 📋 ระบบจัดการงานและช่วยเหลือ (Slash Commands)

สำหรับระบบสั่งงาน คุณสามารถพิมพ์คำสั่งในช่องแชท Discord โดยขึ้นต้นด้วยเครื่องหมายทับ (`/`) ได้เลยครับ

### 1. `/help` (คู่มือ)

เรียกดูคู่มือคำสั่งทั้งหมดของบอท

### 1. `/assign` (มอบหมายงาน)

ใช้สำหรับมอบหมายงานให้คนในเซิร์ฟเวอร์

- **วิธีใช้:** พิมพ์ `/assign` จากนั้นระบบจะมีช่องให้กรอกข้อมูล:
  - `user` (คนที่จะรับงาน)
  - `task` (ชื่องาน หรือรายละเอียดงาน)
  - `deadline` (กำหนดส่ง เช่น 10/06/2026)
- **ตัวอย่าง:** `/assign user:@JohnDoe task:ทำรายงานประจำเดือน deadline:10/06/2026`
- **การทำงาน:** บอทจะขึ้นข้อความให้คุณตรวจสอบ เมื่อคุณกดปุ่ม **✅ ยืนยัน** บอทจะบันทึกข้อมูลลง Google Sheets ทันทีและประกาศบอกทุกคน

### 2. `/task` (ตรวจสอบและส่งงาน)

ใช้สำหรับดูว่าตัวเองมีงานอะไรที่ถูกสั่งไว้ และยังไม่ได้ทำบ้าง

- **วิธีใช้:** พิมพ์ `/task`
- **การทำงาน:** บอทจะลิสต์รายชื่องานที่คุณยังทำไม่เสร็จขึ้นมาให้เฉพาะคุณเห็น หากคุณทำงานไหนเสร็จแล้ว ให้กดที่ปุ่ม **✅ เสร็จเรียบร้อย** ใต้งานนั้น บอทจะไปติ๊กถูกใน Google Sheets และเปลี่ยนสีพื้นหลังให้ พร้อมประกาศบอกในช่องแชทว่าคุณทำงานนี้เสร็จแล้ว!

### 3. `/summary` (ดูสรุปงานค้าง)

ใช้สำหรับดูภาพรวมว่า ณ ตอนนี้คุณยังมีงานอะไรที่ค้างอยู่บ้าง (เอาไว้ดูเฉยๆ เพื่อเตือนความจำ)

- **วิธีใช้:** พิมพ์ `/summary`
- **การทำงาน:** บอทจะโชว์ Embed แจ้งเตือนรายการงานที่ยังคงค้างอยู่ทั้งหมดพร้อมกำหนดส่งอย่างสวยงาม

## 🛠️ โครงสร้างไฟล์สำหรับนักพัฒนา

หากต้องการแก้ไขโค้ด สามารถดูไฟล์ต่างๆ ได้ตามนี้:

- `index.js`: ไฟล์ตั้งค่าการทำงานหลักของตัวบอท
- `deploy-commands.js`: รันไฟล์นี้เมื่อต้องการลงทะเบียน / อัปเดตคำสั่ง `/` บน Discord
- `features/assign.js`: โค้ดส่วนที่ดูแลคำสั่ง `/assign`
- `features/task.js`: โค้ดส่วนที่ดูแลคำสั่ง `/task`
- `features/summary.js`: โค้ดส่วนที่ดูแลคำสั่ง `/summary`
- `package.json`: ใช้สำหรับกำหนดการ Build เป็นไฟล์ `.exe` (ด้วยคำสั่ง `npm run build`)
